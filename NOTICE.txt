Credits (GPL reference material)
--------------------------------
During development the public, GPL-licensed WordPress plugins "Pathao Courier",
"Redx for WooCommerce" and "SteadFast API" were studied to learn the data
formats of their APIs (field names, endpoints, webhook behaviour, order meta
keys used for backwards compatibility). The current code base is a new
implementation with a different architecture, but acknowledges that origin
because GPL work that was adapted must stay attributed. Legacy order-meta keys
(ptc_*, _redx_tracking_id, steadfast_*) are read so parcels created by those
plugins keep working.

Paperfly and Sundarban modules are based on publicly available community
documentation / manual workflow only; no vendor code is included.
